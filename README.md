# מעבדת VR – מערכות הידראוליות ופנאומטיות · APEX TRAINING

מעבדה וירטואלית למשקפי **Meta Quest 3**: חדר מעבדה עם עמדות עבודה. בכל עמדה יש לוח אימון הידראולי שמפעילים בידיים, לוח בקרה, שרטוט ISO חי והודעות טקסט על כל פעולה.
הגרסה הזו כוללת את **כל 26 המעבדות** (72 סימולציות) באולם אחד, בשורות של 6 לפי סדר הפרקים.
- **לובי (הדף הראשי של ה-VR):** מדריך המעבדות לפי 4 החלקים – לחיצה על מעבדה מעבירה אליה.
- עמדה נבנית במלואה רק כשמתקרבים אליה (כך המשקפיים לא מועמסים), ומתפרקת כשמתרחקים.
- בכל עמדה: לוח אימון תלת-ממדי, לוח בקרה, שרטוט ISO חי, מדים והודעות טקסט על כל פעולה.

## העלאה ל-GitHub Pages (פעם ראשונה, בלי להתקין כלום)

1. נכנסים ל-github.com ונרשמים / מתחברים.
2. למעלה מימין: **+** ← **New repository**.
   - Repository name: למשל `apex-vr-lab`
   - בוחרים **Public** (באתר חינמי זה תנאי ל-GitHub Pages).
   - לוחצים **Create repository**.
3. בדף הריק של המאגר לוחצים על הקישור **uploading an existing file**.
4. פותחים את התיקייה `apex-vr-lab` במחשב, מסמנים את **כל מה שבתוכה** (Ctrl+A) וגוררים לחלון הדפדפן.
   חשוב: גוררים את התוכן – לא את התיקייה עצמה. בשורש המאגר צריכים להופיע `index.html`, `stations.js` והתיקיות `assets`, `engine`, `labs`, `platform`, `vendor`.
5. למטה לוחצים **Commit changes**.
6. **Settings** ← בתפריט הצד **Pages** ←
   Source: **Deploy from a branch** · Branch: **main** · תיקייה: **/(root)** ← **Save**.
7. אחרי דקה-שתיים מופיעה בראש דף ה-Pages הכתובת, למשל:
   `https://שם-המשתמש.github.io/apex-vr-lab/`

## כניסה מהמשקפיים

1. במשקפיים: **הגדרות ← תנועה ומעקב (Movement tracking) ← מעקב ידיים** – מפעילים.
2. פותחים את **Browser** ומקלידים את הכתובת (כדאי לשמור כסימנייה).
3. לוחצים על **"כניסה ל-VR 🥽"** ומאשרים את ההרשאה.
4. מניחים את הבקרים בצד – הידיים מופיעות. אפשר לעבוד גם עם בקרים.

| מה עושים | איך |
|---|---|
| לדעת מה רכיב עושה | נוגעים בו עם האצבע המורה |
| להפעיל רכיב (כמו לחיצה באתר) | צביטה על הרכיב עצמו |
| ללחוץ על כפתור | דוחפים אותו עם האצבע |
| להזיז ידית / מחוון / לסובב כפתור | צביטה (אגודל + אצבע) ליד החלק, מזיזים או מסובבים את כף היד, משחררים |
| לעבור למקום אחר בחדר | הולכים, או מצביעים על הרצפה וצובטים |
| תפריט (מדריך המעבדות, המעבדה הבאה/הקודמת, שקיפות, צלילים, עזרה) | הופכים את כף היד השמאלית כלפי הפנים |

במחשב רגיל אותו קישור עובד עם עכבר ומקלדת: גרירה = הסתכלות, W/A/S/D או גלגלת = הליכה, לחיצה = הפעלה.

## עדכון אחרי שינויים

ב-GitHub נכנסים למאגר ← **Add file ← Upload files** ← גוררים רק את הקבצים שהשתנו (עם אותם שמות ובאותן תיקיות) ← **Commit changes**.
אחרי כדקה העדכון באוויר. במשקפיים מרעננים את הדף.

## הוספת מעבדה נוספת לחדר

כל המעבדות של האתר רצות על אותו מנוע, ולכן כל מעבדה יכולה להפוך לעמדה:

1. שמים בתיקייה `labs/` את קובץ המעבדה (`ch02.js`, `ch07.js` …). הקבצים נוצרים מקוד המעבדות של האתר (אותו קוד בדיוק).
2. ב-`stations.js`:
   - מוסיפים את הקובץ ל-`labFiles`.
   - מוסיפים שורה ל-`stations` עם מספר הפרק ומיקום על הרצפה, למשל
     `{id:'ch07',lab:7,pos:[-4.2,-3.4],rotY:0.35}`
3. לוח הבקרה, הלוח התלת-ממדי, השרטוט, המדים וההודעות נבנים אוטומטית.
   כדי להפעיל חלקים ישירות על הרכיבים (ידית שסתום, כפתור סיבובי, כפתורי הפעלה) מוסיפים `bind` – ההסבר בראש הקובץ `stations.js`.

## מבנה התיקייה

| תיקייה / קובץ | תוכן |
|---|---|
| `index.html` | הדף הראשי |
| `stations.js` | **הקובץ שעורכים**: החדר, העמדות והחלקים שמופעלים בידיים |
| `labs/` | קוד המעבדות (זהה לאתר) |
| `engine/` | מנוע ההידראוליקה המשותף (פיזיקה, סמלי ISO, דגמי הרכיבים) |
| `platform/` | פלטפורמת ה-VR: חדר, ידיים, תנועה, לוח בקרה, פאנלים, הודעות |
| `vendor/` | ספריית התלת-ממד (three.js) עם תמיכה ב-VR |
| `assets/` | דגמי ידיים ובקרים, לוגו |
| `tools/` | סקריפט הבנייה ובדיקת הידיים בסימולטור Quest 3 (לשימוש Claude) |

## אם משהו לא עובד

- **הכפתור כתוב "VR לא זמין"** – בודקים שהכתובת מתחילה ב-`https://` ושנפתחה בדפדפן של המשקפיים.
- **לא רואים ידיים** – מפעילים מעקב ידיים בהגדרות המשקפיים ומניחים את הבקרים בצד.
- **שינוי לא מופיע** – מחכים דקה ומרעננים; לפעמים צריך לסגור ולפתוח את הלשונית.

## צלילים
כל עמדה משמיעה צלילים מסונתזים (בלי קובצי שמע): זמזום משאבה ומנוע שמשתנה עם הלחץ, רחש שמן שזורם לפי הספיקה, שריקה של שסתום פריקה פתוח, קליק של שסתום כיווני ושל כפתורים, ומכה עמומה כשבוכנה מגיעה לסוף המהלך.
